# Presença Digital — Social Assets

Repositório público utilizado exclusivamente para armazenar mídias já aprovadas para publicação nas redes sociais da Presença Digital.

## Regras
- Não armazenar credenciais, documentos privados, dados de clientes ou arquivos internos.
- Somente imagens e artes já consideradas seguras para publicação pública.
- O MazyOS permanece privado; este repositório funciona apenas como ponte pública de mídia para o Metricool.
